# Web 工作台视觉设计

2026-09-29 从队友提供的本地副本 `前端优化版/DGXHackthon/spark-devflow-agent/web/` 合入当前项目。本文记录合入后的工作台现状；后端接口仍以 `agent/server.py` 为准。

## 当前布局

- 深色工作台：桌面端为左侧会话栏、中间聊天区、右侧决策轨迹三栏；窄屏保留侧栏和轨迹切换。
- 登录页左侧介绍、右侧口令卡片；窄屏改为上下排列。视觉底层为紫黑色 MicroSlats 动态背景，WebGL2 不可用时保留静态背景。
- 卡片、输入区与登录区采用深色玻璃材质；消息和轨迹保持较实的底色，保证文字可读。
- 右侧轨迹、长期记忆和新对话使用分段控件；输入区的模型档位、工作区与权限使用统一样式的下拉菜单，高亮框默认停在已选项上，并随鼠标悬停或键盘聚焦滑动；模型设置下拉使用 GlideSelect。快捷任务只填入输入框，由用户决定是否发送。
- 输入区的“+”可选择最多 6 张 PNG、JPEG、GIF 或 WebP 图片（单张 8 MB）；发送时上传至当前会话，历史消息保留缩略图。图片通过 OpenAI 兼容的 `image_url` 内容块交给独立的本地视觉端点（默认 Qwen，可用 `AGENT_VISION_BASE` / `AGENT_VISION_MODEL` 配置），不受文字模型档位变动影响。
- 本地提供 Inter 和 Instrument Serif 字体及 OFL 许可；运行时不请求外部字体服务。

## 代码入口与验证

- `web/src/main.ts` 负责工作台骨架、背景和交互挂载；`web/src/glass.css` 与 `web/src/motion.css` 管理视觉和动效。
- `web/src/components/` 存放视觉组件；`web/src/ui/` 中的适配层将组件接入现有 TypeScript DOM 工作台。
- 开发：`cd web && npm ci && npm run dev`；构建：`npm run build`。开发服务器将 `/api` 代理到本机 `127.0.0.1:9000`。
- 2026-09-29 合入后，TypeScript 与 Vite 构建通过；本地生产页面的桌面工作台、桌面及手机登录页已截图检查。节点上的真实模型链路仍需部署后验证。
