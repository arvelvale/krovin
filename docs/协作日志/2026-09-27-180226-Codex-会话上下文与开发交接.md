## 项目定位与文件结构

- 仓库：https://github.com/arvelvale/spark-devflow-agent
- 本地：`D:\Develop\DGXHackthon\spark-devflow-agent`。
- 项目是开发流 Agent，提供 Web 面板和 CLI。输入来自 Linear issue、Obsidian 纪要、用户文字或语音，串联任务拆解、计划、代码修改、测试、开发日志和状态同步。

- 文档有历史设计残留，应优先读架构「实现状态」及当前代码配置。OpenShell、NAT 等早期设想不能直接当成已实现功能；流程也不是全离线。

## 提示词优化的职责入口
